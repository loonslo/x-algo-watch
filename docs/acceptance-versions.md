# 逐版本阅读档案验收

维护日期：2026-10-22。

用户追加要求：普通读者可以直接查看版本变化及通俗易懂的可能影响，每次迭代都有独立文件。这里的迭代对应上游源码提交；没有新提交的重复检查不创建新版本。

## 实现与边界

- README 顶部直达 `versions/README.md`，目录按上游提交时间倒序，逐行展示一句话变化、解读状态和复核优先级。日期统一使用 UTC，完整提交号防止重名。
- 每个版本独立文件包含：通俗变化、可能影响、创作者现在要做什么、源码前后对比、原始证据；长 JSON 和 README 修改片段折叠展示。删掉的设置链接到旧版本源码，目录来源链接到源码树。
- 基础说明由既存证据与固定模板生成，不增加模型请求。默认关闭、代码删除、规则名单变化、测试样例变化分别解释，不将源码变化直接等同于上线、流量涨跌或账号限流。
- 未确认与驳回清楚标注；确认版本从 digest 精确保留所有者批准的原文。模型审计及尚未确认的模型草稿不会被搬到读者页面。确认决策缺少对应速报时停止生成，不能冒充已确认。
- 正常 publish 在持久化证据后生成档案；confirm 在追加速报和决策后同步档案，再提交、关闭 Issue。历史测试不写档案。登记重核附在原版本，不替换原始迭代变化。
- 生成文件不是进度来源。`python -m x_algo_watch.versions` 可从本项目证据重建；不读手册、不访问上游、不改 data 或 digest，不消耗模型额度。人工解读仍走 Issue 确认流程。
- 只将版本目录及日期＋完整 SHA 的 Markdown 纳入发布白名单；生成前全量扫描敏感内容，拒绝符号链接，其他代码或任意 Markdown 不可随产物发布。
