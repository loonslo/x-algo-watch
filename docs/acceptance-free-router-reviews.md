# 免费自动路由与多轮校验验收

日期：2026-10-22。所有者要求使用 OpenRouter 免费自动路由，不固定型号；考虑免费模型可能漏信息或理解错误，在原复核上增加一到两轮。本次采用增加两轮。

## 实际规则

- 配置起草和复核均为 `openrouter/free`。仅允许该免费路由或显式 `:free` 型号，不放开付费自动路由。JSON 输出要求不变，不对自动选择的型号强加 MiniMax 专用参数。
- 起草后分别进行综合复核、源码事实与重要遗漏核对、机制推断与读者理解核对。三轮均读取相同原始证据、同一稿件及完整输出协议，不接收其他复核者裁决。
- 任一轮不同意，合并全部异议，不采用多数票。最多反馈修订一次，再重新核对全部三关；即使稿件相同，修订后的核对也不能沿用旧裁决。仍有分歧不显示用户正文，只在研究附录保留原稿。
- 每个阶段结构校验失败最多纠错一次。正常每版 4 次调用，有一轮语义修订、无结构纠错时共 8 次；与旧调用共用每日 50 次。额度不足、服务延期或主动运行达到 20 分钟时保留缓存与审计，后续只补缺少阶段，避免 35 分钟 Actions 超时强杀。
- 发布端检查当前要求的三轮记录及合并裁决，省略某轮、降低轮数或用通过结论覆盖异议都会被拒绝。提示词、输出协议、路由与要求轮数共同计算研究指纹。旧已通过稿保留原复核记录，不冒充通过新增关卡。
- 审计保留请求路由与接口返回的实际型号；未返回则记未知。各角色可能选到同一型号，不能承诺异模型独立复核。[官方免费路由说明](https://openrouter.ai/docs/guides/routing/routers/free-router)明确自动选择免费型号、按所需能力筛选，并在响应 `model` 字段返回实际型号。

## 本地与远程验证

Windows / Python 3.14.0：第一轮完整测试 **227 passed in 79.09s**，包含真实上游历史回放；最终相关回归 **75 passed in 44.16s**，覆盖新增规则指纹与修订中途断点。所有模型响应用测试替身，没有读取密钥或进行真实 API 调用。

已覆盖：四个调用角色/提示词分离、共享精确 reader 协议、任一复核否决、全部通过发布、最多一次语义修订、修订后全部重新核对、接口型号与未知值的缓存恢复、付费路由拦截、无效轮数拦截、结构失败只纠错一次、额度/连接/时间边界续跑、缺失关卡及伪造合并裁决拦截。模拟端到端同时验证修订成功与最终仍有分歧两条分支；修订中途用尽预算后只补剩余两关，合计仍为 8 次。未经人工确认不写入 digest。

## 未验证项

UTC 2026-10-22 的程序预算已用满 50 次，不因切换路由重置。真实免费自动路由的 JSON 质量、所选型号、三轮核对效果和实际延迟须在预算重置后验证，模拟响应不能替代该验收。多轮检查降低风险，不能保证没有遗漏；只核对提供的证据包，不能声称通读整个项目。历史研究队列仍待续写；连续 24 小时定时可靠性亦未通过。
