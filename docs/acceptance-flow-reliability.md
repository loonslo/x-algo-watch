4. 引用搜索：汇总各文件前八个定义，每个前后版本各搜索一次，再按原符号及顺序筛选各文件引用；原数量上限和缺口说明保留。只接受提取出的名称，以单个择一表达式等价搜索，通过标准输入传递，避免 Windows 命令行长度限制。
