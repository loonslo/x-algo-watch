# P1 历史回放样本

本目录最初由本机只读回放生成，覆盖 `47c1bcd → 7f2ca2b`，共 50 个提交。回放固定时间为 `2026-10-21T09:00:00+00:00`；这份初始样本本身不表示定时监测已部署。后续真实检测、模型与确认事件继续追加，实际验收见 docs/ 下的记录。

后续登记表重核以 verification 事件追加到月记录，不改变上述 50 个提交的成功进度。确认与模型调用也使用独立事件；不要把事件数当成上游提交数。

- `records/2026-10.md`：基线与逐提交证据；月份按检查发生时间（UTC），不是上游提交月份。
- `status.md`：可以从记录重建的状态。
- `verification.yaml`：最新目标提交的登记核验及自动观察表（登记项数随人工维护变化）；人工外部来源尚未核对，明确标为 unreviewed。
- `project-context/提交号.json`：对应版本当前准备的项目证据包。
- `project-context/提交号-内容摘要.json`：某次模型研究实际读取的不可变证据快照；补证据不会覆盖旧快照。

给读者的模型机制研究保存在 [逐版本档案](../versions/README.md)。模型推测、复核分歧与人工确认分别标注，不能把这些事件或输入文件的数量当作已完成研究的版本数。

上线前明确是否使用此目录作为初始进度。探索、测试、其他范围的回放使用 `--output runtime/独立名称`。
